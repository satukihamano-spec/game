# 顔アップ用の画像フォルダ

対戦のときと「情報を聞く」ときに表示する、2Dの顔画像をここに入れます。
画像がない人物は、ゲームが自動で描いた顔を表示します（画像を入れるまでの代わり）。

## 置き方

```
public/portraits/
├─ npc01/          ← 顔ID（下の表）ごとにフォルダを作る
│   ├─ neutral.png   通常（これだけは必ず用意する）
│   ├─ smile.png     笑顔
│   ├─ wary.png      警戒
│   ├─ confused.png  困惑
│   ├─ angry.png     怒り
│   ├─ nervous.png   緊張
│   ├─ surprised.png 驚き
│   └─ sad.png       悲しみ
├─ npc02/
│   └─ neutral.png   （表情の画像がない場合は neutral が使われる）
└─ player/          ← プレイヤーの顔（対戦のとき、左下に小さく出る）
    └─ neutral.png
```

- 形式は **.png / .webp / .jpg** のどれでもOK（同じ名前なら png → webp → jpg の順に使われる）
- おすすめのサイズ：**縦長 600×800 くらい**。顔が上の方にある「胸から上」の構図
- 同じ人物の表情の画像は、**顔の位置・大きさ・背景をそろえる**（切り替えたとき自然に見える）
- 口パクはしないので、**口は閉じた形でそろえる**と自然です
- 画像を入れたら、ブラウザを再読み込みするだけで反映されます（コードの変更は不要）

## 顔ID と NPC の対応

顔IDは `src/data/npcs.ts` の並び順で決まっています（ゲームのたびに同じ人物には同じ顔が使われます）。
特定の人物に別の顔IDを使いたいときは、`npcs.ts` のその人物に `portrait: 'npc05'` のように書きます。
